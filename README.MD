# Cosmetic-bot
## Инструкция к запуску
- Создать google таблицу с данными товаров
- Получить файл-ключ, создав сервисный аккаунт с доступом к таблице
- Скопировать `.env.example` в `.env` и указать:
  - API token бота
  - название файла ключа
  - id администратора
- При использовании Prometheus скопировать `web.yml.example` в `web.yml` и
  установить собственный bcrypt-хеш пароля.
- Запустить docker-compose

Файлы `.env`, `web.yml`, ключ сервисного аккаунта и локальные данные бота не
должны попадать в Git.
